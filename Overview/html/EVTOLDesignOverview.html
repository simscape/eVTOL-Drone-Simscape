Overview

Vertical Take-Off and Landing (VTOL) aircraft represent a transformative advancement in aviation, offering unique capabilities such as hovering, vertical flight, and efficient transitions between flight modes. As the demand for urban air mobility and advanced aerial vehicles increases, the development of efficient and reliable VTOL systems becomes crucial. eVTOLs are more efficient than quadcopters because they utilize energy-saving fixed-wing flight, whereas quadcopters depend on energy-intensive hovering. This project contains Simscape™ based workflows and utilities that help you tackle VTOL design challenges by focusing on three core areas: battery sizing, powertrain component design, and control system tuning.

Get Started

(a) Double-click on the eVTOLDroneSimscape PRJ file (in the root folder) to setup the project and get started.
(b) To learn about the system model and its architecture, see Model Overview.

Components

This project includes the following component subsystems: Battery, Motor, Propeller, and Vehicle (Airframe Powertrain). Each component has dedicated test harness models in its respective HarnessModel folder.
